CityPulse

Calls come in from all over the city. Laya, a System 1 decision model running on this Mac, reads each call and decides 🔥 Fire 🚑 Ambulance 🚨 Police or 🚫 Ignore (prank), plus how urgent it is, with a calibrated probability for every option, all in a single forward pass (no text generation). The code then sends the nearest free unit across the map.

🧠 What Laya is asked

Every call goes to POST /api/decide on the local server, which runs agent.predict({"caller_transcript": …}, questions). Laya scores every option at its own [MASK] token and returns a probability per option. There's no prompt to parse and no text generation.
